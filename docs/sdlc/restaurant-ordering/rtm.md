# Requirements traceability matrix: Restaurant ordering service

Every requirement traces forward to design, code, tests and the release. Every test traces back to a requirement. Update this file in the same PR as the change.

How to read it (filled at the end of the Phase 4 build, 2026-10-17):
- **Code** names the main files and the PR that built them (#3 skeleton, #4 core, #5 auth, #6 restaurants, #7 menu, #8 tables, #9 orders, #10 realtime, #11 reports). Paths are under `src/main/kotlin/io/github/phongmanh/restaurant/`; migrations under `src/main/resources/db/migration/`.
- **Tests** lists the system and NFR tests (`ST-…`, test-plan §4, added in Phase 5 on 2026-10-17), the acceptance tests (`AT-…`, run in Phase 5) and the integration tests (`IT-…`). The `IT` lists come from the Req column of each design's test table. Six links were added here and CR-009 (approved 2026-10-17) wrote them into the designs: IT-TBL-13, IT-ORD-22, IT-RT-08 and IT-RT-12 named no requirement, and IT-ORD-16 and IT-REP-02 also cover NFR-I18N-01's time zone.
- **Result** is the integration tests' result. A requirement whose checks are a load test, a dashboard or an operations drill has none until Phase 5 or 6.
